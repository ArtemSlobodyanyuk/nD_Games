# Джерела графіки

Звичайні шахові фігури: набір **Chessnut**, автор Alexis Luengas.
Завантажені без змін із https://github.com/lichess-org/lila/tree/master/public/piece/chessnut.
Оригінальний проєкт: https://github.com/LexLuengas/chessnut-pieces.
Ліцензія Apache License 2.0, текст у `pieces/LICENSE.txt`.
Перелік ліцензій Lichess: https://github.com/lichess-org/lila/blob/master/COPYING.md.

`elemental.png` — надане автором гри зображення «Іконки стихійних шахових фігур.png».
Верхній ряд: білі камінь, вогонь, вода, повітря; нижній ряд: чорні в тому самому порядку.
Інтерфейс використовує ділянки оригінального PNG з його прозорістю.
